# You Science Apps 共通機能実装仕様 Ver.1.1 RC

## 1. Portal公開情報

Portalカードには次を表示する。

- 教材名
- 公開状態
- 対象
- 単元
- 教材形式
- 学習難易度
- 学習目標
- タグ
- 更新日
- Version

`level: A/B/C`は内部管理情報であり、Portalには表示しない。
また、公開用`site/catalog/catalog.json`にも含めず、Manifest内だけに保持する。

## 2. 学習難易度

Manifestでは`education.learningDifficulty`に1〜5の整数で保存する。

- 1〜2: 基本
- 3〜4: 標準
- 5: 応用

Portalには数値や星を表示せず、基本・標準・応用だけを表示する。
AIが初期値を提案し、教員が変更できる。

## 3. 分類

### 大分類

- 中学校理科
- 高校物理
- 高校化学
- 高校生物
- 高校地学
- その他

### 対象

- 中1・中2・中3
- 物理基礎・物理
- 化学基礎・化学
- 生物基礎・生物
- 地学基礎・地学
- その他

### 単元・タグ

`categories`はPortalに表示・検索・絞り込みするための、人間が読める単元名である。
`units`は学習指導要領やカリキュラムとの対応を追跡するための、安定した識別IDである。
`tags`は検索補助語として使用する。
Portal固有の編集情報はCatalog overrideに残す。

## 4. 共通機能

1. キーワード検索
2. 大分類・対象・単元・教材形式・学習難易度による絞り込み
3. お気に入り
4. 最近使った教材（最大3件）
5. 教材追加ウィザード

## 5. 端末内保存

お気に入りと最近使った教材はPortalのlocalStorageだけに保存する。

- 個人名を保存しない
- 正答数・学習結果を保存しない
- 外部送信しない
- 端末間同期をしない
- 利用者が一括消去できる
- 共有端末では次の利用者に保存内容が見える可能性を明示する
- 利用後の一括消去を案内する

## 6. レスポンシブ表示

- PC・Chromebook横向き: 教材カード3列
- iPad縦向き・小画面: 教材カード2列

## 7. 教材追加ウィザード

ウィザードは管理ツールであり、生徒向けPortalには表示しない。
GitHubへ自動書き込みせず、ManifestとCatalog追記用JSONを生成する。


## 8. 大型教材の構成

大型教材は複数ファイル構成を標準とする。
詳細は`LARGE-APP-MULTI-FILE-RULE-v1.0.md`を正本とする。
