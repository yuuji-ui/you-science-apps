2. 結果画面の変更
--------------------------------------------------
主要指標を次の4項目へ整理した。
- 初回正答率
- ミスの傾向
- ヒント使用回数
- 前回・自己ベストとの比較

所要時間とパス回数は結果コメント末尾の小さい副情報として表示する。
速度ランキングや最速タイムを強調する演出は追加していない。

通常完了と鬼途中終了の両方で、次の共通経路を使用する。
buildSessionRecord() → buildProgressComparison() → saveRecord() → renderResults()

3. 自己ベスト判定仕様
--------------------------------------------------
comparisonKeyを次の構成で明示生成する。
mode | ソート済みrange集合 | count | challengeKey

rangeは重複を除去して辞書順にソートするため、選択順が違っても同一条件になる。

同一comparisonKey内で次の優先順位を使用する。
1. 最高初回正答率
2. 最少総ミス
3. 最少ヒント
4. 最短時間

大きな「自己ベスト更新！」表示の条件:
- 初回正答率更新
- 同率正答率で総ミス減少
- 同率正答率・総ミスでヒント減少

時間だけ改善した場合:
- meaningfulBest=false
- timeOnlyBest=true
- 「自己ベスト更新！」は表示しない
- 正確さ・自立度を保った時間短縮として小さく表示する

4. 前回比較仕様
--------------------------------------------------
同一comparisonKeyの保存済み最終記録を直前記録とする。
表示は最大2メッセージ。

- 初回正答率の増減または同率
- 最も変化量の大きいミス分類の改善または注意

悪化時は責める表現を使わず、次回の確認行動を提案する。
比較対象がない初回は、今回を記録し次回比較できることだけを表示する。

5. 今日できるようになったこと
--------------------------------------------------
次の順で根拠のある1文を生成する。
- 前回より減ったミス分類
- 初回正解かつヒント0回で2問以上解けた主要type
- 判断材料不足時は「今回の結果を記録しました。次回と比べてみましょう。」

根拠のない称賛は生成しない。

6. 次のおすすめ
--------------------------------------------------
提案は1つだけ表示する。
- ミス分類がある: 最大のミス分類を確認して苦手復習
- 要復習問題がある: そのtypeを別条件で復習
- 全体良好かつ20問未満: 設定画面で次のチャレンジを自分で選ぶ
- その他: 同じ範囲を再度確認

提案だけで自動的に難易度は変更しない。

7. 問題別振り返り
--------------------------------------------------
初回正解かつヒント2回未満・パスなし:
- 「○ 初回正解」
- 1行の簡潔表示

次のいずれかは「⚠ 要復習」として赤系の枠・背景・文字・記号で表示する。
- 初回不正解
- パス
- ヒント2回以上
- 鬼途中終了の原因問題

要復習の詳細:
- 問題文
- 最初の入力
- 正答
- 日本語のミス分類
- 使用ヒント数とパス・鬼終了情報
- 解説

8. 結果画面の操作
--------------------------------------------------
主要操作:
- 苦手を別条件で復習
- 同じ範囲でもう一度
- トップへ

学習記録は弱いpill表示とした。

苦手を別条件で復習:
- 初回不正解・パス・ヒント2回以上だけをvariantSourceへ渡す
- 同じtype＋別物質＋別数値で再生成して直接開始
- variantRetry=falseまたは対象0問なら非表示

同じ範囲でもう一度:
- mode / ranges / count / challenge / practiceStyleを復元
- 保存済み問題の再利用ではなくbuildQuestionsで新規生成して直接開始

10. localStorage変更
--------------------------------------------------
既存STORAGE_SCHEMA_VERSION=2とキーを維持。
recordsの読み込み時に古いデータを安全に補完するnormalizeRecord()を追加。

追加・補完フィールド:
- comparisonKey
- challengeKey
- rangesNormalized
- totalMisses
- firstCorrectRate
- completed
- failedEarly
- misses.number / unit / sig / fixed / format
- hints / passes / elapsed

旧rateはfirstCorrectRateへ再利用する。
欠落値・null・古いmisses構造が混在しても記録画面を停止させない。
